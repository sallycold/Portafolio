# Portafolio
"Este repositorio contiene mi portafolio personal y CV digital, diseñado para mostrar mi perfil profesional, habilidades, experiencia y proyectos realizados. La página incluye una sección de presentación personal, información académica y loboral, además de una galería de proyectos con capturas de pantalla, descripciones y enlaces para ver cada trabajo en detalle.

Las webs están desarrollada con HTML, CSS, JavaScript y Bootstrap, utilizando un diseño moderno, responsivo y atractivo para presentar mi trabajo de una manera clara y profesional. El objetivo principal es dar a conocer mi trayectoria, destacar mis habilidades y mostrar de forma visual los proyectos que he desarrollado."
